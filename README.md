# Blue Wave 2026
Independent commemorative merchandise storefront.

## Publishing scope
This repository is the PUBLIC STATIC SITE ONLY. It deliberately excludes:
- PayPal API credentials, Sandbox payment links, and payment server
- Printful order token, order records, customer information, and Fonsora source
- Unverified live checkout or automated fulfillment

The website is an informational launch preview; no payment is accepted on this GitHub Pages build. Final prices, product proofs, fulfillment costs, customer policies, and secure checkout need approval before going live commercially.
